# Interaction Context Map

A dependency-free client-side tool for supporting contextual learning and observations of an interaction. Aimed at foundational Interaction Design students.

## Files
- index.html: interface shell
- style.css: visual system and responsive layout
- scripts/storage.js: localStorage persistence and session management
- scripts/maps.js: map data helpers
- scripts/export.js: JSON import/export
- scripts/app.js: application logic and rendering
- data/examples.json: example task list

## Local persistence
Work is saved to localStorage for the site origin. This is device/browser specific and is not submitted to a server.

## Export/import
Students can export a complete interaction to JSON and import it on another copy of the site/device.

No external libraries or build process are required.
