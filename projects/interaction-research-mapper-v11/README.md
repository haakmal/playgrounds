# Interaction Research Mapper v7

Static browser-based teaching tool for the Interaction Stream.

## v7
- Profiles, empathy maps and horizontal interaction journeys remain linked to a user.
- Evidence is displayed with hierarchical keys, e.g. `PR01/EM01-SA03` and `PR01/JN01-PH02-ST03`.
- Analyse replaces Synthesis. It is an evidence light-table only: no automated interpretation and no note-taking.
- A right-side evidence drawer supports literal search and Profile / Empathy / Journey filters.
- Up to four evidence items can be displayed together.
- The five most recent evidence combinations can be restored; this history stores only key combinations.
- Journey emotion controls sit in a separate upper band; the line is drawn entirely underneath.
- Mobile views are blocked with a desktop/tablet notice.
- Data remains in localStorage and can be exported/imported as JSON.

No build step or external dependencies are required.
