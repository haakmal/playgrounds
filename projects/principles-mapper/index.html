HOW TO USE THIS INTERFACE

Using the Principles Map

Start with a location: a screen, control, object, transition, room, or relationship between physical and digital parts. Choose the principle that helps you notice something there, then describe what you observe.

Visibility
What can the person perceive about the system or object?
Feedback
How does it respond to the person’s action?
Affordance
What action does it appear possible to take? Add one or more signifiers when useful.
Mapping
How does the control relate to its outcome?
Constraints
What actions are limited, prevented, or guided?
Consistency
Does it behave like similar things elsewhere?
