# Groupings

A small browser-based tool for randomly arranging a roster into groups or review assignments. I found myself and my tutors often relying on spreadsheets to make groups of students for peer review assignments so this web app was just a logical progression! It's open to anyone who needs to group things toghether but I assume it's mostly going to be names of students!

## How to use

1. Enter names one per line in the roster text field
2. Select what arrangement format is needed:
   a. Groups: Assign names into groups
   b. Assignment: Assign names individual peers
   c. Select how many per group/assignment.
3. Generate orders and shuffle entries if needed
4. Print the current results or copy directly into Moodle/email

The app runs locally. Open `index.html` in a web browser. No build step or dependencies are required.
