SYSTEM INSIGHT LAB

How to use this tool

Use this local workspace after mapping a system on paper, a whiteboard or through other field material.

  1. Capture data points as observations, mutations or insights.
  2. Use Observe and Analyse to record what is present and how you currently read it.
  3. Use Connect to create optional, named relationships between entries.
  4. Review the Atlas to create named threads and inspect selected entries.
  5. Use History to remove records from view or restore them later.

The tool stores records in this browser. It does not interpret or generate connections for you.
